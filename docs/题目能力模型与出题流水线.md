# 题目能力模型与出题流水线

## 一、产品判断

“基于知识点出题”只解决了考什么，不能决定题目是否有教学价值。一道可用的题目还需要明确考查目标、题型、认知层级、情境、设问方式、解题策略、常见错误、评分规则、难度与安全状态。

因此，题目系统不应把“大模型生成的一段文字”直接当成题目，而应把模型放在候选题生产环节，由受控蓝图、可信资料、规则校验、求解验证和教师审核共同约束。

## 二、核心对象

| 对象 | 作用 | 关键边界 |
|---|---|---|
| 出题蓝图 `AssessmentBlueprint` | 描述考什么、怎么考、难到什么程度 | 不包含具体答案 |
| 公开题面 `AssessmentItemPublic` | 给学生展示题干、选项、素材和作答方式 | 不下发答案和评分密钥 |
| 私有答案 `AssessmentKeyPrivate` | 保存答案、解析、评分点、干扰项原因和多解法 | 只在服务端判题后按权限返回 |
| 题目版本 `QuestionVersion` | 固化每次生成、编辑、审核和发布结果 | 已发布版本不可被静默覆盖 |
| 学生作答 `Attempt` | 记录一次真实作答过程 | 与题目版本、学生、会话、幂等键绑定 |
| 学习证据 `LearningEvidence` | 把作答转为对知识和能力的可解释证据 | 完成题目不等于掌握知识点 |

## 三、题目属性体系

### 1. 考查目标

- 主知识点、辅助知识点、前置知识点
- 学习目标：识记、理解、应用、分析、综合、评价
- 核心能力：运算、推理、建模、空间想象、数据分析、表达证明
- 考查权重：每个知识点和能力在本题中的贡献比例

### 2. 题面形态

- 题目类型：单选、多选、填空、计算、解答、证明、探究、开放题
- 交互方式：文字、函数图、几何作图、数轴、统计图、实验、口语
- 情境类型：纯学科、生活应用、跨学科、图表数据、实验观察
- 素材类型：无素材、短文、图片、表格、动态图、实验步骤

### 3. 出题方式

- 定义或性质直接考查
- 条件变式、结论变式、逆向设问
- 错误诊断与纠错
- 参数变化与规律探索
- 多知识点综合
- 真实情境建模
- 一题多问、递进式支架
- 一题多解与方法比较

### 4. 解题结构

- 标准解法、可选解法、最短解法
- 关键步骤、必要前提、评分点
- 提示阶梯：轻提示、中提示、完整提示
- 常见错误、错误发生步骤、干扰项原因
- 可迁移方法与同类题识别线索

### 5. 质量与运营

- 预估难度、实测难度、区分度、平均用时
- 来源、版权、适用考试、课标版本、年份
- 相似题指纹、重复度、曝光次数、安全等级
- 规则校验、求解器验证、教师审核、发布状态

## 四、出题流水线

1. **确定蓝图**：选择知识点、能力、题型、难度、情境与出题方式。
2. **检索可信资料**：只读取授权课标、教材、例题、题型模板和已审核题目。
3. **生成候选题**：模型按固定结构返回候选题，不直接发布。
4. **确定性校验**：检查字段、数值范围、选项唯一性、单位、公式和答案格式。
5. **求解验证**：由规则求解器或独立解题模型复算；需要多解时验证各解法等价性。
6. **去重与安全检查**：检查题库相似度、原题复现风险、答案泄漏和曝光上限。
7. **教师审核**：高风险、证明题、开放题和新题型必须人工审核；记录修改原因。
8. **版本化发布**：公开题面与私有答案分开存储，发布后生成不可变版本号。
9. **作答与判题**：记录答案、步骤、用时、提示、修改次数和题目版本。
10. **形成证据**：按题目对知识点与能力的权重更新证据，再由掌握模型计算状态。

## 五、题库页面职责

题库页面应包含三个层次：

- **历史题目**：按知识点、题目类型、出题方式、解题策略、难度、结果和来源筛选。
- **出题工作台**：配置蓝图，预览检索依据，生成候选题，展示校验结果并提交审核。
- **题目详情**：展示题面、属性、解题策略、多解法、常见错误、历史表现和版本记录。

首期界面可先用本地示例演示“蓝图配置—候选生成—质量门禁”，但不能把演示按钮描述为已接入正式出题服务。

## 六、个人学习记录中的“擅长题目属性”

擅长属性必须从多次有效作答聚合，而不是从一次答对或学生自我陈述直接推断。每一项至少展示：

- 属性名称，例如“函数图象题”“条件变式”“待定系数法”；
- 正确率、样本量、平均用时和提示使用率；
- 置信度与统计时间窗；
- 对应的知识点和代表题目；
- 是否只是一种偏好，还是已经形成可用于教学调度的能力证据。

同理，“不擅长”也应定位到题目属性和错误步骤，不能简单等同于某个知识点未掌握。

## 七、首期质量门禁

- 没有可信知识依据时不生成事实性题目；
- 公开题面永远不携带答案字段；
- 单选题必须唯一正确，数值题必须复算通过；
- 题目与已发布题相似度过高时阻止发布；
- 证明题、开放题和高难题必须教师审核；
- 每次生成、修改、审核、发布和撤回都有可追溯记录；
- 学生端只消费已发布版本，作答事件必须支持幂等与撤销重算。
